## 一、贝叶斯公式基础

$$
P(Y|X)=\frac{P(X|Y)\,P(Y)}{P(X)}
$$

| 项 | 名称 | 含义 |
| --- | --- | --- |
| $P(Y)$ | 先验概率 | 类别本身出现的概率 |
| $P(X\|Y)$ | 似然 | 给定类别时，特征出现的概率 |
| $P(Y\|X)$ | 后验概率 | 看到特征后，判断类别的依据 |
| $P(X)$ | 证据 | 特征出现的概率 |

---

## 二、「朴素」是什么

> **朴素 = 特征条件独立假设（naive）**

一句话：**朴素，就是天真地假设所有特征之间相互独立，互不影响。**

$X$ 是多个特征 $X_1, X_2, \dots, X_n$。要算 $P(X_1, X_2, \dots, X_n | Y)$，真实情况下特征之间大多有关联（比如身高和体重相关），联合概率很难估计。

朴素贝叶斯做了一个很强的简化假设：

> 在给定类别 $Y$ 的条件下，各个特征 $X_1, X_2 \dots X_n$ **相互独立**。

于是联合概率可以拆成乘积：

$$
P(X_1,X_2,\dots,X_n|Y)=\prod_{i=1}^{n}P(X_i|Y)
$$

这个假设**现实里几乎很少严格成立**，只是为了简化计算，所以叫「朴素 / 天真（naive）」。

### 举例：垃圾邮件分类

- 特征：包含词 A、词 B、词 C；
- 朴素假设：**如果这是垃圾邮件，词 A 出现与否，不会影响词 B、词 C 是否出现**；
- 真实情况：词语之间明显有关联，这个假设是强行简化。

### 特点

- ✅ 优点：计算简单、训练快，小数据集也能用，适合文本分类；
- ❌ 缺点：**特征独立假设经常不成立**，有时会损失精度。

## 三、三种朴素贝叶斯模型对比

> 核心区别：**对特征 $P(X_i|Y)$ 的概率分布假设不一样**。三者都保留「朴素」的条件独立假设，只是特征类型不同，选不同分布。

### 3.1 多项式朴素贝叶斯 MultinomialNB

| 项目 | 内容 |
| --- | --- |
| 适用数据 | **离散计数特征** |
| 分布假设 | 特征服从**多项式分布**，描述事件发生次数 |
| 输入要求 | 特征是非负整数（词频 count） |
| 典型场景 | 文本分类（词袋，单词出现次数） |
| 原理 | 计算每个类别下，每个词出现的概率 |
| 细节 | 自带平滑（拉普拉斯平滑），解决训练集里某些词概率为 0 的问题 |

> 例：邮件里「中奖」出现 2 次、「转账」出现 1 次，用它做垃圾邮件分类。

### 3.2 伯努利朴素贝叶斯 BernoulliNB

| 项目 | 内容 |
| --- | --- |
| 适用数据 | **二值 0-1 特征** |
| 分布假设 | 伯努利分布（0/1 单次试验） |
| 含义 | 只代表**有没有这个特征，不关心出现多少次** |
| 典型场景 | 文本分类（词是否存在，不是词频） |

> 例：邮件是否包含「中奖」，出现 1 次和出现 100 次都记为 1。
> 与 Multinomial 的区别：Multinomial 看**次数**，Bernoulli 只看**有无**。

### 3.3 高斯朴素贝叶斯 GaussianNB

| 项目 | 内容 |
| --- | --- |
| 适用数据 | **连续数值特征** |
| 分布假设 | 连续特征服从**高斯（正态）分布** |
| 思路 | 训练时对每个类别，计算该类别下每个特征的**均值、方差**；预测时代入正态概率密度公式算出 $P(X_i\|Y)$ |
| 典型场景 | 鸢尾花数据集（花瓣长度、宽度这类连续实数） |

> 例：身高、体重、温度这类连续变量。

### 3.4 快速对比表

| 模型 | 特征类型 | 分布 | 经典例子 |
| --- | --- | --- | --- |
| GaussianNB | 连续实数 | 高斯正态分布 | 鸢尾花，身高体重 |
| MultinomialNB | 离散计数（≥0 整数） | 多项式分布 | 词袋词频文本分类 |
| BernoulliNB | 二值 0/1 | 伯努利分布 | 词是否在文档中出现 |

## 四、补充考点：拉普拉斯平滑

**问题**：训练集中某个词在某类别下一次都没出现，$P(X_i|Y)=0$，连乘后整个概率直接为 0，预测失效。

**拉普拉斯平滑**：分子 +1，分母 + 类别特征总数，**避免概率为 0**。

> 多项式 / 伯努利朴素贝叶斯会用到；高斯朴素贝叶斯一般不需要（因为用的是概率密度而非计数）。

## 五、代码实践：GaussianNB 完整流程

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import accuracy_score, classification_report

# 1. 加载数据集
iris = load_iris()
X, y = iris.data, iris.target          # 4 个连续特征，3 个类别
class_names = iris.target_names

# 2. 划分训练集、测试集
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

# 3. 构建高斯朴素贝叶斯模型并训练
gnb = GaussianNB()
gnb.fit(X_train, y_train)

# 4. 预测 + 评估
y_pred = gnb.predict(X_test)
acc = accuracy_score(y_test, y_pred)
print(f"\n测试集准确率：{acc:.2f}")
print(classification_report(y_test, y_pred, target_names=class_names))

# 5. 拿一条新样本预测
sample = [[5.1, 3.5, 1.4, 0.2]]
pred = gnb.predict(sample)
prob = gnb.predict_proba(sample)
print(f"\n新样本预测类别：{class_names[pred[0]]}")
print("各类别概率：", prob)
```

**要点**

- 鸢尾花是**连续特征**，因此选 `GaussianNB`；
- `predict_proba()` 返回每条样本属于各类别的概率；
- `classification_report()` 一次给出精确率、召回率、F1 与支持度。

## 六、易混点

MultinomialNB 统计**次数**；BernoulliNB 只看**有无**。

比如一句话：「中奖 中奖」

- Multinomial：「中奖」计数 = 2；
- Bernoulli：「中奖」= 1（存在）。

---

## 七、本章小结与考点

1. 「朴素」指**条件独立性假设**：给定类别时，各个特征相互条件独立；
2. 三种模型的区别在于对 $P(X_i|Y)$ 的**分布假设**不同：连续用高斯、计数用多项式、二值用伯努利；
3. 拉普拉斯平滑解决「某特征在某类别下概率为 0 导致连乘为 0」的问题；
4. 朴素贝叶斯**计算简单、训练快**，适合文本分类与小数据集；
5. 高斯朴素贝叶斯用于连续特征（如鸢尾花），一般不需要拉普拉斯平滑。
