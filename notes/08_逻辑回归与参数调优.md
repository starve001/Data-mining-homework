## 一、逻辑回归的定位

| 项目 | 说明 |
| --- | --- |
| 名称 | 逻辑回归（Logistic Regression） |
| 任务 | **分类**（不是回归） |
| 输出 | 样本属于各类别的**概率** |
| 类别 | 有监督学习 |

> **易错点**：名字里带「回归」，但它解决的是**分类**问题。

---

## 二、完整建模流程

### 2.1 导入库

```python
from sklearn.linear_model import LogisticRegression
from sklearn import datasets
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
```

### 2.2 加载数据

```python
data_bc = datasets.load_breast_cancer()
```

二分类数据集：`target` 中 `0` 与 `1` 分别代表恶性 / 良性。

### 2.3 划分训练集与测试集（分层抽样）

```python
X_train, X_test, y_train, y_test = train_test_split(
    data_bc.data, data_bc.target,
    test_size=0.25,
    stratify=data_bc.target)       # 分层抽样
```

> **`stratify` 的作用**：按标签比例分层抽样，**防止训练集与测试集的类别分布偏差过大**。类别不均衡时尤其重要。

### 2.4 标准化

```python
ss = StandardScaler()
X_train_new = ss.fit_transform(X_train)     # 训练集：fit + transform
X_test_new = ss.transform(X_test)           # 测试集：只 transform
```

### 2.5 实例化、训练、预测

```python
logi_model = LogisticRegression(max_iter=500)   # max_iter 防止迭代不收敛告警
logi_model.fit(X_train_new, y_train)

y_predict = logi_model.predict(X_test_new)
logi_model.score(X_test_new, y_test)            # 准确率
```

## 三、各类别概率预测

`predict()` 只给类别，`predict_proba()` 给出**属于每个类别的概率**。

```python
y_proba = logi_model.predict_proba(X_test_new)   # 形状 (n_samples, 2)

result_1 = y_proba[:, 1]     # 类别 1 的概率
result_2 = y_proba[:, 0]     # 类别 0 的概率
```

### 按真实标签拆分概率

```python
predict_good = result_1[y_test == 1]    # 实际为 1，预测为 1 的概率
predict_bad  = result_1[y_test == 0]    # 实际为 0，预测为 1 的概率
```

### 可视化概率分布与决策边界

```python
plt.rcParams['font.sans-serif'] = ['Microsoft YaHei']
plt.rcParams['axes.unicode_minus'] = False

plt.figure(figsize=(10, 5))
plt.hist(predict_bad,  label='恶性，标签为1', color='red')
plt.hist(predict_good, label='良性，标签为0', color='green')
plt.axvline(x=0.5, color='black', linestyle='--', linewidth='2',
            label='决策边界x=0.5')
plt.legend()
```

> **决策边界 0.5**：概率 > 0.5 判为类别 1，否则判为类别 0。两组直方图分得越开，说明模型区分能力越强。

## 四、参数调优：GridSearchCV

### 4.1 为什么要调参

模型的默认参数不一定适合当前数据。**网格搜索（Grid Search）** 会穷举给定的参数组合，对每一种组合做交叉验证，选出平均得分最高的那一组。

### 4.2 基本用法

```python
from sklearn.model_selection import GridSearchCV

lg_gs = LogisticRegression(solver='liblinear')

gs_estimator = GridSearchCV(
    lg_gs,                                  # 1. estimator：需要调参的模型实例
    param_grid={'C': [0.01, 0.1, 1, 10, 100]},   # 2. param_grid：待调参数字典
    cv=5,                                   # 3. cv：交叉验证折数，默认 5
    scoring='accuracy'                      # 4. scoring：评估指标
)

gs_estimator.fit(X_train_new, y_train)      # 训练（内部做 5×5 次训练评估）
```

### 4.3 参数说明

| 参数 | 含义 |
| --- | --- |
| `estimator` | 需要调参的模型实例 |
| `param_grid` | 参数字典：**key 是模型参数名，value 是该参数所有取值的列表** |
| `cv` | 交叉验证折数，默认为 5；每种参数组合训练评分 `cv` 次 |
| `scoring` | 评估指标，默认 `None`（用 estimator 自带的评估方法） |

> **书写规则**：
> - 字典的 key **一定是对应模型的参数名**；
> - key 对应的 value **一定是一个列表**，列表中是该参数的所有可用取值。

### 4.4 读取调优结果

```python
gs_estimator.best_params_      # 最优参数组合
gs_estimator.best_estimator_   # 用最优参数重新训练好的模型
gs_estimator.best_score_       # 最优参数下的交叉验证平均分
```

## 五、本章小结与考点

1. 逻辑回归解决的是**分类**问题，输出概率；
2. `train_test_split` 的 `stratify` 用于**分层抽样**，保持类别比例；
3. `predict()` 给类别，`predict_proba()` 给概率；`y_proba[:, 1]` 取正类概率；
4. 决策边界默认 0.5；
5. `GridSearchCV` 四要素：`estimator` / `param_grid` / `cv` / `scoring`；
6. `param_grid` 的 value **必须是列表**，key 必须是模型真实参数名；
7. 调优后通过 `best_params_` / `best_estimator_` / `best_score_` 三个属性取结果。
