## 一、模型误差与过拟合

### 1.1 模型误差的组成

模型的总误差通常可理解为三部分：

| 成分 | 含义 | 过大的后果 |
| --- | --- | --- |
| **偏差（Bias）** | 预测值与真实值之间的**系统性**误差 | 模型过简单 → **欠拟合** |
| **方差（Variance）** | 预测结果之间的**离散程度**，反映对训练数据变化的敏感度 | 模型过复杂 → **过拟合** |
| **数据本身的误差** | 采集、测量或随机因素造成的误差 | 通常无法完全消除 |

### 1.2 什么是过拟合

**过拟合**：模型在训练集上表现非常好，但在新的、未见过的数据上表现较差。

**原因**：模型过于复杂，除了学习数据的真实规律外，还学习了训练数据中的**噪声和偶然性**，因此泛化能力不足。

---

## 二、偏差与方差的权衡

偏差和方差通常存在**矛盾关系**：

- 降低偏差 → 往往需要提高模型复杂度 → 但可能导致方差增大；
- 降低方差 → 往往需要限制模型复杂度 → 但可能导致偏差增大。

随着模型复杂度增加，**偏差下降、方差升高**，而**总误差呈现先下降后上升**的趋势。因此不能只追求更复杂的模型或更低的训练误差，而应在偏差与方差之间寻找平衡。

### 减少过拟合的方法

1. 选择合适的模型复杂度和多项式阶数；
2. 增加训练数据量，提高数据代表性；
3. 使用**正则化**方法限制模型参数；
4. 通过**交叉验证**选择合适的模型和超参数；
5. 删除无关特征或进行特征选择；
6. 同时关注训练集、验证集和测试集的表现。

---

## 三、正则化与 Ridge 回归

### 3.1 为什么需要正则化

普通线性回归通过最小化均方误差（MSE）拟合模型：

$$
MSE = \sum_i \left(y_i - f(x_i)\right)^2
$$

当特征较多、特征之间存在较强相关性，或模型复杂度较高时，线性回归可能过拟合。为限制参数大小、降低过拟合风险，可在损失函数中加入**正则化项**。

### 3.2 Ridge 回归（L2 正则化）

$$
L_{Ridge} = MSE + \alpha \sum_i w_i^2
$$

- $w_i$：回归系数；$\alpha$：正则化强度；
- 效果：使回归系数**整体变小并接近于 0**，但通常**不会将系数完全变为 0**；
- 因此模型仍会保留较多特征。

---

## 四、Lasso 回归

$$
L_{Lasso} = MSE + \alpha \sum_i |w_i|
$$

- L1 正则化会使**一部分回归系数直接变为 0**；
- 因此 Lasso 不仅能缓解过拟合，还可以进行**特征选择**，得到更稀疏、更易解释的模型。

---

## 五、Ridge 与 Lasso 的区别

| 对比方面 | Ridge 回归 | Lasso 回归 |
| --- | --- | --- |
| 正则化类型 | L2 正则化 | L1 正则化 |
| 惩罚项 | $\sum_i w_i^2$ | $\sum_i \lvert w_i \rvert$ |
| 对系数的影响 | 使系数接近 0 | 可使部分系数变为 0 |
| 特征选择 | 通常不能直接选择特征 | 可以进行特征选择 |
| 适用特点 | 特征之间存在相关性，希望保留更多特征 | 特征较多，希望得到稀疏模型 |

### `alpha` 参数的作用

| `alpha` 变化 | 效果 |
| --- | --- |
| **越大** | 系数收缩越明显、模型复杂度越低、抗过拟合能力越强 |
| **越小** | 越接近普通线性回归，保留更多特征，但过拟合风险增加 |

实际应用中应通过**验证集或交叉验证**选择合适的 `alpha`，在拟合能力与泛化能力之间取得平衡。

## 六、代码实践：多项式 + 正则化

### 6.1 构造非线性数据

```python
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.preprocessing import PolynomialFeatures
import numpy as np
import matplotlib.pyplot as plt

X = np.random.uniform(-3, 3, size=100)
y = 0.5 * X**2 + 2 + np.random.normal(0, 1, size=100)   # 二次关系 + 噪声

plt.scatter(X, y)
```

### 6.2 高阶多项式展开

```python
X = X.reshape(-1, 1)                     # 升维为二维，符合 sklearn 要求

pf = PolynomialFeatures(degree=40)       # 40 阶 —— 故意制造过拟合
X_train = pf.fit_transform(X)
```

### 6.3 线性回归 vs 岭回归

```python
lr = LinearRegression()
ridge = Ridge()

lr.fit(X_train, y)
ridge.fit(X_train, y)

lr_predict = lr.predict(X_train)
ridge_predict = ridge.predict(X_train)

print(lr.score(X_train, y))       # 训练集分数很高，但可能过拟合
print(ridge.score(X_train, y))    # 正则化后更平稳
```

**观察**：40 阶多项式下，普通线性回归的拟合曲线会在数据点之间剧烈震荡（方差极大），而 Ridge 的曲线明显更平滑 —— 这正是正则化抑制过拟合的直观体现。

### 6.4 标准化处理

```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
X_train_new = ss.fit_transform(X_train)
print(X_train_new.max(), X_train_new.min())     # 约 1 / 约 -1

lr_new = LinearRegression()
ridge_new = Ridge()
lr_new.fit(X_train_new, y)
ridge_new.fit(X_train_new, y)
```

> **为什么需要标准化**：多项式展开后不同特征的量级差异极大（$x$ 与 $x^{40}$），线性类模型对**特征量纲敏感**，不标准化会导致数值不稳定、系数求解困难。标准化后各特征均值为 0、标准差为 1。

## 七、本章小结与考点

1. **总误差 = 偏差 + 方差 + 数据本身误差**；
2. 偏差大 → 欠拟合；方差大 → 过拟合；
3. 模型复杂度增加：偏差 ↓、方差 ↑，总误差先降后升；
4. **Ridge = MSE + L2**，系数趋近 0 但不为 0，保留全部特征；
5. **Lasso = MSE + L1**，部分系数直接为 0，可做特征选择、得到稀疏模型；
6. `alpha` 越大正则化越强、模型越简单；
7. 多项式阶数过高必然过拟合，正则化与标准化是常用的两个应对手段；
8. 标准化必须**只在训练集上 `fit`**，再转换测试集，防止数据泄漏。
