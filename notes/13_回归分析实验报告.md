## 三、数据预处理

Pandas 对**离散型数据**进行转换的方法有三种：

| 方法 | 作用对象 | 说明 |
| --- | --- | --- |
| `map()` | Series | 字典映射，逐值替换 |
| `apply()` | Series / DataFrame | 按元素或按轴作用，可配合 lambda |
| `applymap()` | DataFrame | 逐元素作用（新版本推荐 `DataFrame.map`） |

> **为什么要编码**：sklearn 回归模型**只能接受数值特征**，字符串列必须先转成整数。

### 3.1 使用 map() 替换 sex 和 smoker 列

```python
df['sex'] = df['sex'].map({'female': 0, 'male': 1})
df['smoker'] = df['smoker'].map({'no': 0, 'yes': 1})
df.head()
```

### 3.2 替换 region 列的字符串

```python
set(df['region'].to_list())      # 先查看有多少个区域

df['region'] = df['region'].map({'northeast': 0, 'northwest': 1,
                                 'southeast': 2, 'southwest': 3})
df.head(10)
```

### 3.3 使用 apply() 改写字符串转换（与 map 等价）

`apply()` 按元素作用在 Series 上，配合 lambda 条件表达式可实现与 `map()` 字典映射相同的编码。

```python
# 重新载入原始数据，避免在已编码的列上二次转换
df_apply = pd.read_csv('../data/insurance.csv', header=0)

df_apply['sex'] = df_apply['sex'].apply(lambda x: 1 if x == 'male' else 0)
df_apply['smoker'] = df_apply['smoker'].apply(lambda x: 1 if x == 'yes' else 0)
df_apply['region'] = df_apply['region'].apply(
    lambda x: {'northeast': 0, 'northwest': 1, 'southeast': 2, 'southwest': 3}[x])
df_apply.head()

# 验证 apply() 结果与 map() 结果完全一致
(df_apply[['sex', 'smoker', 'region']].values == df[['sex', 'smoker', 'region']].values).all()
```

> **关键点**：必须**重新载入原始数据**再演示 apply 写法，否则会在已编码的列上二次转换（例如把已经是 0/1 的值再当字符串处理），得到错误结果。

## 四、构建一元回归模型

保险费用（charges）与是否吸烟（smoker）存在很强的正相关性，因此先构建一元线性回归模型。

```python
X = df[['smoker']]
Y = df[['charges']]

lr = LinearRegression()      # 实例化
lr.fit(X, Y)                 # 训练
lr.score(X, Y)               # 评估（R²）
```

### 可视化：散点图与拟合直线

```python
plt.figure(figsize=(6, 4.2))
plt.scatter(X, Y, alpha=0.5, s=18, label='Data')
xx = np.array([[0], [1]])
plt.plot(xx, lr.predict(xx), 'r-', lw=2,
         label='fit: y=%.0fx+%.0f' % (lr.coef_[0][0], lr.intercept_))
plt.xlabel('smoker (0=no, 1=yes)')
plt.ylabel('charges')
plt.title('Univariate: smoker vs charges')
plt.legend(); plt.grid(alpha=0.3); plt.tight_layout()
plt.show()
```

## 五、构建二元回归模型

为了使模型更精确，在 age 与 smoker 两个特征上构建二元回归模型。

```python
X1 = df[['age', 'smoker']]
Y1 = df[['charges']]

lr1 = LinearRegression()
lr1.fit(X1, Y1)
lr1.score(X1, Y1)
```

### 可视化：分组散点 + 两条拟合线

```python
plt.figure(figsize=(7, 4.5))
plt.scatter(df[df['smoker'] == 0]['age'], df[df['smoker'] == 0]['charges'],
            s=18, alpha=0.5, label='non-smoker')
plt.scatter(df[df['smoker'] == 1]['age'], df[df['smoker'] == 1]['charges'],
            s=18, alpha=0.5, label='smoker')

ages = np.linspace(df['age'].min(), df['age'].max(), 100)
for s in [0, 1]:
    plt.plot(ages, lr1.predict(pd.DataFrame({'age': ages, 'smoker': [s] * 100})),
             '--', lw=2, label='fit smoker=%d' % s)
plt.legend(); plt.grid(alpha=0.3); plt.tight_layout()
plt.show()
```

> **注意**：用 `pd.DataFrame` 构造预测输入时，**列名必须与训练时的特征名一致**，否则会触发 sklearn 的 `X does not have valid feature names` 警告。

## 六、构建多元回归模型

将 charges 设为标签，其他所有列设为特征。

```python
y_data = df['charges']
x_data = df.drop('charges', axis=1)

x_train, x_test, y_train, y_test = train_test_split(
    x_data, y_data, test_size=0.20, random_state=1)

lr2 = LinearRegression()
lr2.fit(x_train, y_train)
lr2.score(x_test, y_test)      # 在测试集上评估
```

### 可视化：预测值 vs 真实值

```python
y_pred = lr2.predict(x_test)

plt.figure(figsize=(6, 5))
plt.scatter(y_test, y_pred, alpha=0.6, s=22)
lim = [y_test.min(), y_test.max()]
plt.plot(lim, lim, 'r--', lw=1.5)      # 对角线 = 完美预测
plt.xlabel('Actual charges')
plt.ylabel('Predicted charges')
plt.title('Multivariate: prediction vs actual (R2=%.4f)' % lr2.score(x_test, y_test))
plt.grid(alpha=0.3); plt.tight_layout()
plt.show()
```

### 可视化：三种模型 R² 对比

```python
models = ['Univariate(smoker)', 'Bivariate(age+smoker)', 'Multivariate(all)']
scores = [lr.score(X, Y), lr1.score(X1, Y1), lr2.score(x_test, y_test)]

bars = plt.bar(models, scores, color=['#4C72B0', '#DD8452', '#55A868'])
plt.ylim(0, 1.05); plt.ylabel('R2 Score')
plt.title('R2 Comparison: Uni / Bi / Multi-variate')
for b, s in zip(bars, scores):
    plt.text(b.get_x() + b.get_width() / 2, s + 0.01, format(s, '.4f'), ha='center')
plt.grid(axis='y', alpha=0.3); plt.tight_layout()
plt.show()
```

## 七、实验总结

| 模型 | 特征 | 评估方式 | R² |
| --- | --- | --- | --- |
| 一元回归 | smoker | 训练集 | ≈ 0.62 |
| 二元回归 | age, smoker | 训练集 | ≈ 0.72 |
| 多元回归 | 除 charges 外全部列 | 测试集（8:2 划分） | ≈ 0.76 |

1. **数据预处理**：sklearn 回归模型只能接受数值特征，课件使用 `df.loc[]` 条件替换和 `apply()` + 自定义函数对 `sex`、`smoker`、`region` 三个离散型字符串列做**标签编码**，转换为整数；`df.info()` 确认转换后各列均为数值类型，`df.isna().sum()` 确认无空值，无需缺失值处理。

2. **特征越多，拟合越好**：从一元（仅 smoker）到二元（age + smoker）再到多元（全部特征），R² 由 0.62 逐步提升到 0.76，说明**是否吸烟是最主要的单一驱动因素**，年龄、BMI 等提供了增量信息。

3. **评估口径的变化**：一元、二元模型直接在**训练集**上 `score()`，多元模型先 `train_test_split` 切分再在**测试集**上评分，后者更能反映模型的**泛化能力**，是更规范的评估方式。

## 八、大白话理解多元回归

> 用一段代码讲清「多元拟合」到底在做什么。

- **一元拟合**是「一个原因猜一个结果」：比如只看是否吸烟猜保费。
- **多元拟合**就是同时看好几个原因猜结果：吸烟、年龄、BMI、性别、地区……一起上，让模型自己学出一套「加权公式」：

$$
\text{保费} \approx w_1 \times \text{吸烟} + w_2 \times \text{年龄} + w_3 \times \text{BMI} + \dots + b
$$

模型的活儿就是把每个 $w$（权重/系数）调得让算出来的数和真实保费尽量接近。哪个因素重要，它的 $w$ 就大。

### 代码逐行理解

```python
y_data = df['charges']                 # 答案：要预测的东西（保费），单独拎出来
x_data = df.drop('charges', axis=1)    # 题目：除了保费外的所有列，都当线索
```

就像做题：`x_data` 是试卷上的已知条件，`y_data` 是标准答案。`axis=1` 意思是「删掉这一列」。

```python
x_train, x_test, y_train, y_test = train_test_split(
    x_data, y_data, test_size=0.20, random_state=1)
```

把 1338 条数据随机切成两堆：80% 当「平时练习题」（训练集），20% 当「期末考卷」（测试集）。

- 模型**只用练习题学习**，从没见过考卷的答案；
- `random_state=1` 是「洗牌种子」，固定它每次切出来的卷子都一样，结果可复现。

```python
lr2 = LinearRegression()        # 实例化：请出一个「线性回归」学生，此时他还没学
lr2.fit(x_train, y_train)       # 训练：给他练习题和答案，他自己悟出各个 w 和 b
```

`fit` 之后模型内部就记下了那套权重，相当于背下了公式。

```python
lr2.score(x_test, y_test)       # 评估：拿考卷测他
```

把考卷的题目（`x_test`）喂给模型算预测值，再和考卷答案（`y_test`）对比，输出 R² 分数。R² = 0.76 可以粗略理解成：保费的差异里，约 **76%** 能被这几个因素「解释」，剩下 24% 是模型抓不到的（个体差异、随机波动等）。

### 为什么这样比一元/二元那两步更规范

前面一元、二元是 `lr.score(X, Y)` —— 用练习题本身考试，学生可能死记硬背也拿高分（**过拟合**），分数虚高。多元这步是用没见过的题考试，考出来的才是**真实水平**。这也是为什么第 6 章要花那么大篇幅讲过拟合：训练集分数越完美，越要留个心眼。

## 九、本章小结与考点

1. sklearn 回归只能接受**数值特征**，离散字符串列必须编码（`map` / `apply` / `applymap`）；
2. 演示 `apply` 写法时必须**重新载入原始数据**，避免二次转换；
3. `df.info()` 看类型、`df.isna().sum()` 看空值，是数据预处理的固定两步；
4. 用 `pd.DataFrame` 构造预测输入时，**列名要与训练时一致**；
5. 特征越多 R² 越高，但**在测试集上评估**才反映泛化能力；
6. `train_test_split(test_size=0.2, random_state=1)` 是标准的 8:2 划分写法；
7. 训练集评分偏高往往是过拟合信号，应结合测试集分数判断。
