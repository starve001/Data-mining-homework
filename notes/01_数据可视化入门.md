## 二、Matplotlib 基础绘图

### 2.1 创建画布与绘制折线

```python
import matplotlib.pyplot as plt

time = ['20200401', '20200402', '20200403', '20200404', '20200405']
china = [93, 78, 73, 55, 75]
math = [78, 45, 34, 56, 28]

plt.figure(figsize=(5, 4), dpi=100)   # 5×4 英寸、100 dpi 的画布
plt.plot(time, china)                 # 绘制第一条折线
plt.plot(time, math)                  # 同一画布上叠加第二条折线
plt.show()
```

**要点**

- `plt.figure(figsize=(w, h), dpi=n)` 负责创建画布，`figsize` 单位是英寸，`dpi` 决定清晰度；
- 多次调用 `plt.plot()` 会把多条曲线叠加到**同一张图**上，用于多组数据对比；
- `plt.show()` 才会真正渲染输出。

### 2.2 散点图与随机数据

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(19680801)              # 固定随机种子，保证结果可复现

nbPoints = 50
x = np.random.standard_normal(nbPoints)   # 标准正态分布
y = np.random.standard_normal(nbPoints)
colors = np.random.rand(nbPoints)         # [0,1) 均匀分布，映射为颜色
area = (30 * np.random.rand(nbPoints)) ** 2   # 面积按平方缩放

plt.scatter(x, y, s=area, c=colors, alpha=0.5)
plt.show()
```

**要点**

- `np.random.seed()` 必须放在所有随机数生成**之前**；
- `plt.scatter()` 中 `s` 控制点面积、`c` 控制颜色、`alpha` 控制透明度；
- 点的面积按平方缩放是为了让视觉面积与数值成正比。

## 三、Pandas 常见图表命令

`DataFrame.plot()` 是 Pandas 在 Matplotlib 之上封装的绘图接口，列名自动成为标签。

## 六、数据预处理实战

### 6.1 读取多个 CSV 文件

```python
import pandas as pd

# 2015、2017 用逗号分隔；2016 用分号分隔 —— 分隔符不同要分别指定
df2015 = pd.read_csv('../data/2015_data.csv', sep=',')
df2016 = pd.read_csv('../data/2016_data.csv', sep=';')
df2017 = pd.read_csv('../data/2017_data.csv', sep=',')
```

> **易错点**：`read_csv` 的默认分隔符是逗号。遇到分号分隔的文件必须显式传 `sep=';'`，否则整行会被当成一列。

### 6.2 纵向合并与索引重置

```python
df = pd.concat([df2015, df2016, df2017], axis=0)   # 按行拼接
df.index = [i for i in range(df.shape[0])]         # 重置为连续整数索引
```

`axis=0` 表示按行（纵向）拼接；拼接后索引会重复，需手动重置。

### 6.3 重命名列（中英文对照）

```python
df.columns = ['area', 'year', 'total_value', 'one_value', 'two_value',
              'three_value', 'zero_value', 'inout', 'population', 'pay',
              'student', 'hospitalt', 'realty']
```

| 原列名 | 含义 | 原列名 | 含义 |
| --- | --- | --- | --- |
| area | 地区 | inout | 货物进出口总额 |
| year | 年份 | population | 年末总人口 |

| one_value | 第一产业增加值 | student | 普通高等学校在校学生数 |
| two_value | 第二产业增加值 | hospitalt | 医院、卫生院数 |

### 6.4 缺失值诊断与填充

```python
df.isnull().sum()                                        # 逐列统计缺失数量
df['realty'] = df['realty'].fillna(value=df['realty'].mean())   # 用均值填充
```

处理顺序固定为「先 `isnull().sum()` 诊断，再决定 `fillna` / `dropna`」。

## 七、批量绘图：多子图循环

```python
def plotType(data):
    fig, axes = plt.subplots(5, 2, figsize=(18, 25))   # 5 行 2 列
    axes = axes.ravel()                                # 二维坐标轴数组展平为一维

    for i, ax in enumerate(axes):
        value_column = data[i + 1]
        ax.plot(dt2015[data[0]], dt2015[value_column], marker='o', label='2015')
        ax.plot(dt2016[data[0]], dt2016[value_column], marker='o', label='2016')
        ax.plot(dt2017[data[0]], dt2017[value_column], marker='o', label='2017')
        ax.set_title(plot_title[i])
        ax.set_xticks(range(len(dt2015[data[0]])))
        ax.set_xticklabels(dt2015[data[0]], rotation=90)   # 地区名旋转 90° 防止重叠
        ax.legend(loc='best')

    fig.tight_layout()      # 自动调整间距，避免标签被裁切
    plt.show()
```

**要点**

- `plt.subplots(5, 2)` 返回 `(fig, axes)`，`axes` 是 **二维数组**，用 `.ravel()` 展平后即可用单层循环遍历；
- 面向对象写法中用 `ax.xxx()` 而不是 `plt.xxx()`，可以精确定位到某个子图；
- 类别较多时用 `set_xticklabels(..., rotation=90)` 旋转标签；
- `fig.tight_layout()` 解决子图标题、标签互相遮挡的问题。

## 八、本章小结与考点

1. 画布由 `plt.figure(figsize, dpi)` 创建，`plt.show()` 才输出；
2. 同形多组数据叠加到一张图用多次 `plt.plot()`；
3. `scatter` 的 `s`（大小）、`c`（颜色）、`alpha`（透明度）是最常考的三个参数；
4. 不同分隔符的 CSV 必须分别指定 `sep`，这是多文件读取最常见的坑；
5. `pd.concat(axis=0)` 纵向合并后要重置索引；
6. 缺失值处理遵循「先诊断、后填充」；
7. 多子图用 `plt.subplots` + `ravel()` 循环，中文显示必须先设 `font.sans-serif`。
