## 一、混淆矩阵（二分类，0 负 / 1 正）

二分类预测一共就 4 种情况，对应混淆矩阵 4 个单元格：

| 符号 | 全称 | 中文含义 | 通俗解释 |
| --- | --- | --- | --- |
| TP | True Positive | 真正例 | 真实是 1（正），预测为 1（正）✅ |
| FN | False Negative | 假负例 | 真实是 1（正），预测为 0（负）❌ **漏检** |
| FP | False Positive | 假正例 | 真实是 0（负），预测为 1（正）❌ **误报** |
| TN | True Negative | 真负例 | 真实是 0（负），预测为 0（负）✅ |

> **记忆口诀**：
> **第一个单词 True/False：预测结果对不对；第二个 Positive/Negative：模型预测出来是什么类别。**
> - True：预测正确；False：预测错误
> - Positive：模型输出正类 (1)；Negative：模型输出负类 (0)

### 举例：疾病检测（患病 = 正 1，健康 = 负 0）

- TP：真得病，模型判断得病
- FN：真得病，模型判断健康（**漏诊**）
- FP：没病，模型判断得病（**误诊**）
- TN：没病，模型判断健康

### 二分类混淆矩阵表格写法（考试标准）

| 真实 \ 预测 | 预测为正（1） | 预测为负（0） |
| --- | --- | --- |
| 真实为正（1） | TP | FN |
| 真实为负（0） | FP | TN |

## 二、衍生指标

### 1. 准确率 Accuracy

$$
Acc=\frac{TP+TN}{TP+TN+FP+FN}
$$

全部样本预测正确的比例。

> **缺点**：样本不均衡时不准。比如 99% 都是负样本，无脑猜负就能有 99% 准确率。

### 2. 精确率 Precision（查准率）

$$
P=\frac{TP}{TP+FP}
$$

**模型预测为正的样本里，真正是正的比例。**

> 垃圾邮件场景：预测是垃圾邮件的样本中，确实是垃圾邮件的有多少。

### 3. 召回率 Recall（查全率）

$$
R=\frac{TP}{TP+FN}
$$

**真实所有正样本中，被模型找出来的比例。**

> 疾病诊断：所有病人里，被检测出来的病人占比。

### 4. F1 分数

$$
F_1=\frac{2\cdot P\cdot R}{P+R}
$$

精确率和召回率的**调和平均**，综合衡量模型。

> **考点区分**：
> - 精确率：预测出来的正样本靠谱吗？
> - 召回率：真实的正样本抓全了吗？

## 三、代码实践

### 3.1 导入库

```python
from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import (accuracy_score, precision_score,
                             recall_score, f1_score, confusion_matrix)
import matplotlib.pyplot as plt
import seaborn as sns
```

### 3.2 建模与预测

```python
iris = datasets.load_iris()
knc = KNeighborsClassifier(n_neighbors=3)

X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42)

knc.fit(X_train, y_train)
y_pred = knc.predict(X_test)
knc.score(X_test, y_test)
```

### 3.3 计算评估指标

```python
accuracy_score(y_test, y_pred)     # 准确率
cm = confusion_matrix(y_test, y_pred)
```

### 3.4 seaborn 绘制混淆矩阵

```python
# annot=True  : 在每个单元格中显示数字
# fmt='d'     : 以整数形式显示注释
# cmap='Blues': 使用蓝色调的颜色映射
# center=13   : 将颜色映射的中心值设为 13，更好显示差异
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
            xticklabels=iris.target_names,
            center=13,
            yticklabels=iris.target_names)
plt.figure(figsize=(8, 6))
```

### 3.5 使用 ConfusionMatrixDisplay

```python
from sklearn.metrics import ConfusionMatrixDisplay

# 直接传混淆矩阵
ConfusionMatrixDisplay(cm, display_labels=iris.target_names).plot()

# 直接从模型 + 测试集计算并绘制
ConfusionMatrixDisplay.from_estimator(
    knc, X_test, y_test,
    display_labels=iris.target_names,
    cmap=plt.cm.Blues)
```

> `from_estimator` 一步完成「预测 + 计算混淆矩阵 + 绘图」，是最便捷的写法。

## 四、本章小结与考点

1. 混淆矩阵四要素：TP / FN / FP / TN，记忆口诀看「True/False 对错 + Positive/Negative 预测类别」；
2. 准确率在**样本不均衡**时具有误导性；
3. 精确率关注「预测为正的准不准」，召回率关注「真实的正抓全没有」；
4. F1 是精确率与召回率的调和平均；
5. `sns.heatmap` 关键参数：`annot=True` 显示数字、`fmt='d'` 整数、`cmap` 配色；
6. `ConfusionMatrixDisplay.from_estimator()` 可一步完成预测与可视化。
