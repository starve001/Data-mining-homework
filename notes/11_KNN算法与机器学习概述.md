## 一、数据挖掘与机器学习概述

### 1.1 什么是数据挖掘

**数据挖掘**：从大量数据中提取有价值的信息和知识的过程。

### 1.2 机器学习的分类

| 类型 | 是否需要标签 | 目标 | 常见算法 |
| --- | --- | --- | --- |
| **监督学习** | 需要标签 | 预测未知样本的类别/数值 | KNN 分类、逻辑回归、神经网络、决策树、随机森林、支持向量机 |
| **无监督学习** | 不需要标签 | 发现数据中的隐藏结构 | K-Means 聚类、DBSCAN、HDBSCAN |

> **标签数据**：即给数据类别的判断。
> **目标不同**：无监督学习的目标是发现数据中的隐藏结构，监督学习的目标是预测未知样本的类别。

### 1.3 主要任务类型

| 任务 | 说明 | 归属 |
| --- | --- | --- |
| **回归分析** | 标签为连续数值 | 监督学习（**不属于分类**） |
| **分类算法** | 根据样本特征将其分到不同类别，预测未知样本的类别 | 监督学习 |
| **关联分析** | 找出特征之间隐藏的关联关系 | —— |
| **聚类分析** | 根据样本特征归类，训练时**没有标签** | 无监督学习 |
| **异常检测** | 对数据进行异常检测，常与聚类结合使用 | —— |

## 二、KNN 算法原理

**KNN（K-Nearest Neighbors，K 近邻）** 是一种基于「最近邻」的分类算法。

**原理**：给定一个样本，计算它与训练数据集中其他样本的距离，找出距离最近的 **K** 个样本，将这些样本的类别**投票**，最终得到该样本的类别。

**实现步骤**

1. 数据预处理：数据清洗、转换和归一化；
2. 划分训练集和测试集（通常 8:2）；
3. 计算距离：常用**欧氏距离**、曼哈顿距离、切比雪夫距离；
4. 排序并取前 K 个最近邻；
5. 统计 K 个邻居的标签频数，返回**频数最多**的类别。

**优缺点**

- 优点：简单、直观、无需训练；
- 缺点：预测时计算距离复杂度较高，且 **K 的选择对结果影响较大**。

> **K 一般取奇数**：当 K 为偶数时存在平票情况，无法确定分类结果。

## 三、手写 KNN：0 和 1 怎么判断

核心思想：**邻居投票，少数服从多数**。

### 3.1 数据

- 类别 **0**：前 4 个点 `(1,3.5)、(2,7)、(3,10.5)、(4,14)`
- 类别 **1**：后 4 个点 `(5,25)、(6,30)、(7,35)、(8,40)`
- 待测点：`x = (8, 21)`，k=3

### 3.2 第一步：计算欧氏距离

$$
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
$$

| 训练点 | 类别 | 到 (8,21) 的距离 |
| --- | --- | --- |
| (5,25) | **1** | 5.00 ✔ |
| (4,14) | **0** | 8.06 ✔ |
| (6,30) | **1** | 10.30 ✔ |
| (3,10.5) | 0 | 13.82 |
| (7,35) | 1 | 14.14 |
| (2,7) | 0 | 15.65 |
| (8,40) | 1 | 19.00 |
| (1,3.5) | 0 | 19.34 |

取距离最小的前 3 个：`(5,25)→1`、`(4,14)→0`、`(6,30)→1`

> 得到 3 个邻居标签列表：`topk_y = [1, 0, 1]`

### 3.3 第二步：Counter 统计投票次数

```python
votes = Counter([1, 0, 1])
```

统计结果：`1` 出现 **2 次**，`0` 出现 **1 次**。

### 3.4 第三步：most_common 选出票数最多

`votes.most_common(1)` 返回 `[(1, 2)]`

- `(1, 2)`：元组，第一个是类别，第二个是票数；
- `[0]` 取这个元组 → `(1, 2)`；
- `[0]` 取出类别 → `1`。

✅ 最终返回结果是 **1**。

### 3.5 换 k 值，结果就会变

| k | 邻居标签 | 统计 | 结果 |
| --- | --- | --- | --- |
| k=1 | `[1]` | 1 出现 1 次 | `1` |
| k=3 | `[1, 0, 1]` | 1 出现 2 次，0 出现 1 次 | `1` |
| k=5 | `[1, 0, 1, 0, 1]` | 1 出现 3 次，0 出现 2 次 | `1` |
| k=2 | `[1, 0]` | **平票** | 手写版未处理平票 |

> **手写 KNN 的缺陷**：没有处理平票，平票时会取 Counter 内部顺序。

### 3.6 通俗理解

> 0、1 只是给两类样本打的**标签代号**，本身没有数学含义，不是数字大小。
> KNN **不计算待测点等于 0 还是等于 1**，不做大小比较！
> 逻辑：**看周围 k 个已经分好类的邻居，邻居里面 0 多就判 0，1 多就判 1。**

## 四、代码实践

### 4.1 手写 KNN（欧氏距离 + 投票）

```python
import numpy as np
from math import sqrt
from collections import Counter

def distance(k, X_train, Y_train, x):
    # 计算欧氏距离：for 循环遍历所有样本
    distance = [sqrt(np.sum((x_train - x) ** 2)) for x_train in X_train]
    # 返回距离从小到大排序后的索引数组
    nearest = np.argsort(distance)
    # 获取距离最小的前 k 个样本的标签
    topk_y = [Y_train[i] for i in nearest[:k]]
    # 统计前 k 个样本的标签类别以及对应频数
    votes = Counter(topk_y)
    # 返回频数最多的类别
    return votes.most_common(1)[0][0]
```

**关键代码对应位置**

```python
topk_y = [Y_train[i] for i in nearest[:k]]   # 拿到 k 个邻居的标签 [1,0,1]
votes = Counter(topk_y)                      # 统计每个标签出现多少次
return votes.most_common(1)[0][0]            # 返回票数最多那个标签
```

### 4.2 构造数据并预测

```python
X_train = np.array([[1.0, 3.5], [2.0, 7], [3.0, 10.5], [4.0, 14],
                    [5, 25], [6, 30], [7, 35], [8, 40]])
Y_train = np.array([0, 0, 0, 0, 1, 1, 1, 1])
x = np.array([8, 21])

label = distance(3, X_train, Y_train, x)
print(label)     # 1
```

### 4.3 逐步观察中间过程

```python
distances = []
for x_train in X_train:
    d = sqrt(np.sum((x_train - x) ** 2))
    distances.append(d)
    print(d)

np.argsort(distances)      # 返回数组值从小到大的索引值

for i in np.argsort(distances)[0:3]:
    print(distances[i], X_train[i], Y_train[i])
```

> **`np.argsort()` vs `np.argmax()`**：`argsort()` 返回数组值**从小到大排序后的索引**；`argmax()` 返回**最大值所在的位置索引**。

### 4.4 向量化改进版

```python
def knn_predict(X_train, Y_train, x, k):
    distances = [((x_train - x) ** 2).sum() ** 0.5 for x_train in X_train]
    nearest = sorted(range(len(distances)), key=lambda i: distances[i])[:k]
    return Counter(Y_train[i] for i in nearest).most_common(1)[0][0]
```

利用 `np.linalg.norm(X_train - x, axis=1)` 可一次性算出所有距离，避免 Python 循环：

```python
d = np.linalg.norm(X_train - x, axis=1)   # 计算每个点到 x 的距离
nearest = np.argsort(d)[:k]               # 取最近的 k 个
return Counter(Y_train[nearest]).most_common(1)[0][0]
```

## 五、本章小结与考点

1. 机器学习分**监督**（需标签）与**无监督**（不需标签）两大类；
2. **回归**属于监督学习，但**不属于分类**；
3. **聚类**是无监督模型，训练时没有标签；
4. KNN 是**惰性学习算法**：**没有训练过程**，预测时才计算距离、投票；
5. K 一般取**奇数**以避免平票；
6. 手写 KNN 三步：算距离 → `argsort` 排序取前 k → `Counter` 投票取 `most_common`；
7. `np.argsort()` 返回排序后的**索引**，`np.argmax()` 返回**最大值位置**；
8. 标签 0/1 只是类别代号，没有大小含义，KNN 不做数值比较。
