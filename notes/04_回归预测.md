## 一、真值与测量

回归任务中的数据由**真值**和**测量值**构成：真值是我们希望逼近的目标，测量值是实际观测到的、带有误差的数值。回归模型的目标是找到一条最能反映两者关系的曲线/直线。

**最小二乘法**是线性回归的求解基础：选择一组参数，使所有样本的**预测值与真实值之差的平方和**最小。

$$
\min_{w,b} \sum_{i=1}^{n}\left(y_i - (w x_i + b)\right)^2
$$

---

## 二、sklearn 回归的标准流程

sklearn 所有模型遵循统一接口，回归建模固定为五步：

```
1. 加载/构造数据  →  2. 选择模型（实例化）  →  3. 训练 fit()
                              ↓
                     5. 应用 predict(新数据)  ←  4. 预测/评估 predict() / score()
```

## 三、一元线性回归

### 3.1 构造数据

```python
import numpy as np
from sklearn.linear_model import LinearRegression

X_train = np.array([[1], [3], [2], [1], [3]])
y_train = np.array([[14], [24], [18], [17], [27]])
X_test = np.array([[6]])
```

> **sklearn 硬性规则**：特征 `X` 必须是**二维**的。即使只有 1 个特征，也要写成 `[[1], [3], ...]`，不能写成 `[1, 3, ...]`。

### 3.2 实例化 → 训练 → 预测 → 评估

```python
line_model = LinearRegression()          # 实例化：此时 w、b 都还是空的

line_model.fit(X_train, y_train)         # 训练：最小二乘法求出最优 w、b

y_predict = line_model.predict(X_train)  # 预测：代入已训练好的公式
line_model.score(X_train, y_train)       # 评估：返回 R²
```

### 3.3 读取训练出来的参数

```python
print(line_model.coef_)        # 权重 w
print(line_model.intercept_)   # 截距 b
```

| 属性 | 含义 |
| --- | --- |
| `coef_` | 回归系数（权重） |
| `intercept_` | 截距 |

> 注意属性名末尾的**下划线**：sklearn 约定「训练后才产生的属性」以下划线结尾。

### 3.4 应用模型

```python
line_model.predict(X_test)     # 对新样本（x=6）做预测
```

## 四、多元线性回归

### 4.1 数据场景

用两个自变量预测运输时间：

- $x_1$：运输里程
- $x_2$：运输次数
- $y$：总运输时间

公式：

$$
\hat{y} = w_1 x_1 + w_2 x_2 + b
$$

### 4.2 构造特征与标签

```python
X_train = np.array([
    [100, 4], [50, 3], [100, 4], [100, 2], [50, 2],
    [80, 2],  [75, 3], [65, 4],  [90, 3],  [90, 2]
])
y_train = np.array([9.3, 4.8, 8.9, 6.5, 4.2, 6.2, 7.4, 6.0, 7.6, 6.1])
```

**要点**

- 每一行代表一条样本，每一列代表一个特征；
- 10 条样本、2 列特征，`X_train.shape == (10, 2)`；
- `y` 是一维数组，顺序与 `X_train` 的行**一一对应**：第一行 `[100, 4]` 对应 `y` 的第一个值 `9.3`。

### 4.3 训练、预测、读取参数

```python
multi_model = LinearRegression()
multi_model.fit(X_train, y_train)

X_test = np.array([[102, 6]])          # 新样本同样要二维
y_pred = multi_model.predict(X_test)

print("系数coef：", multi_model.coef_)          # [w1, w2]
print("截距intercept：", multi_model.intercept_)  # b
print("预测运输时间：", y_pred[0])
```

- `coef_` 返回 `[w1, w2]`，顺序与 `X` 的**列顺序一致**（第一列 x1、第二列 x2）；
- 示例输出：`coef = [0.0352, 0.9438]`、`intercept = 0.0446`，得到
  $$\hat{y} = 0.0352 x_1 + 0.9438 x_2 + 0.0446$$
  代入 $x_1=102,\ x_2=6$ 得预测时间 ≈ **9.26 小时**。

### 4.4 模型评估

```python
score = multi_model.score(X_train, y_train)   # R²，越接近 1 越好
```

## 五、关键对比：一元 vs 多元

| 对比项 | 一元回归 | 多元回归 |
| --- | --- | --- |
| 公式 | $\hat{y}=w_1x_1+b$ | $\hat{y}=w_1x_1+w_2x_2+b$ |
| X 形状 | 每行 1 个值 `[[1],[3]]` | 每行多个特征 `[100,4]` |
| 代码改动 | —— | **不需要改任何其他代码** |

> `LinearRegression` 会根据 `X` 的列数自动切换一元/多元，只要增加列数即可。

---

## 六、回归数据特点

- **有监督学习**：必须有标签；
- **标签要求连续**：这是回归与分类最本质的区别；
- 判断是否属于回归问题：看流程第一步——标签是否为连续数值。

---

## 七、本章小结与考点

1. 回归建模五步：构造数据 → 实例化 → `fit` → `predict` → `score`；
2. `X` **必须二维**，这是 sklearn 最常见的报错来源；
3. `fit()` **直接修改模型对象本身，没有返回值**；
4. `coef_` / `intercept_` 在训练后才存在，故以下划线结尾；
5. `coef_` 的元素顺序与 `X` 的列顺序一致；
6. 一元与多元共用 `LinearRegression`，只靠特征列数区分；
7. 回归的标签必须是连续值。
